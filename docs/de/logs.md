# Journale

`<source>` ist `/opt/high-fortress-user/src` nach dem Curl-Installer oder das Klonverzeichnis. `YYYYMMDD-HHMMSS` ist der Stempel `date +%Y%m%d-%H%M%S`.

| Pfad                                                                           | Wer schreibt                        | Wann                                                                                                                            |
| ------------------------------------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/install.log                         | scripts/run.sh via hf_init_install_log | Während der Installation.                                                                                                       |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/errors.log                          | hf_log_error()                      | Wenn ein Schritt fehlschlägt.                                                                                                   |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/meta.txt                            | hf_init_install_log                    | Wenn das Journalverzeichnis entsteht.                                                                                           |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/steps/INDEX.tsv                     | hf_set_step_visible                             | Bei jedem Installationsschritt.                                                                                                 |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/aide-init.log                       | service/aide/init-db.sh             | Wenn die Basis zum ersten Mal gebaut wird. Ausweichpfad, wenn HF_LOG_DIR leer ist: `/var/log/high-fortress-user/aide-init.log`. |
| /opt/high-fortress-user/cron/security_logs/aide-YYYYMMDD-HHMMSS.log            | aide.sh                             | Startprüfung und stündliche Prüfung, wenn AIDE läuft.                                                                                  |
| /opt/high-fortress-user/cron/security_logs/rkhunter-YYYYMMDD-HHMMSS.log        | rkhunter.sh                         | Startprüfung und stündliche Prüfung.                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/chkrootkit-YYYYMMDD-HHMMSS.log      | chkrootkit.sh                       | Startprüfung und stündliche Prüfung.                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/clamav-YYYYMMDD-HHMMSS.log          | clamav.sh                           | Startprüfung und Lauf alle 2 Stunden.                                                                                           |
| /opt/high-fortress-user/cron/security_logs/apparmor-detect.log                 | detect-and-apply.sh                 | Jede AppArmor-Profilentscheidung.                                                                                               |
| /opt/high-fortress-user/cron/security_logs/integrity-YYYYMMDD-HHMMSS.log       | integrity.sh                        | Startprüfung.                                                                                                                   |
| /opt/high-fortress-user/cron/integrity.sha256                                  | integrity.sh                        | Startprüfung. Der erste Lauf schreibt die Datei und sendet keine Post.                                                         |
| /opt/high-fortress-user/cron/security_logs/behavior-YYYYMMDD-HHMMSS.log        | behavior.sh                         | Startprüfung.                                                                                                                   |
| /opt/high-fortress-user/cron/behavior.stamp                                    | behavior.sh                         | Startprüfung. Der erste Lauf schreibt die Datei und sendet keine Post. Spätere Läufe lesen Audit-Ereignisse seit diesem Stempel. |
| /opt/high-fortress-user/cron/security_logs/egress-YYYYMMDD-HHMMSS.log          | egress-watch.sh                     | Startprüfung.                                                                                                                   |
| /opt/high-fortress-user/cron/egress.stamp                                      | egress-watch.sh                     | Startprüfung. Der erste Lauf schreibt die Datei und sendet keine Post. Spätere Läufe lesen Kernelzeilen seit diesem Stempel.   |
| /opt/high-fortress-user/cron/quarantine.registry                           | die Quarantäne-Verschiebung        | Wenn eine Datei gespeichert wird. Modus 600.                                                                              |
| /opt/high-fortress-user/cron/security_logs/idle-scan-YYYYMMDD-HHMMSS.log       | idle-scan.sh                        | Verzögerte Prüfung. Ein sauberer Lauf und ein Lauf, der ausfällt, weil ein Spiel läuft, schreiben diese Datei.          |
| /opt/high-fortress-user/cron/security_logs/reboot-notice-YYYYMMDD-HHMMSS.log | reboot-notice.sh                    | Neustart-Hinweis. Ein sauberer Lauf und ein Lauf, der ausfällt, weil ein Spiel läuft, schreiben diese Datei.       |
| /opt/high-fortress-user/cron/security_logs/scan-skip.log                       | apply-scan-skip.sh                  | Wenn eine Zeile von `scan-skip.paths` abgelehnt wird.                                                                            |
| /opt/high-fortress-user/cron/security_logs/clamav-onaccess-YYYYMMDD-HHMMSS.log | clamav-event.sh                     | Wenn die Zugriffsprüfung eine echte Datei findet. Ein Sperrname beendet das Skript, bevor diese Datei geschrieben wird.                                       |
| /opt/high-fortress-user/cron/security_logs/debsums-YYYYMMDD-HHMMSS.log         | debsums.sh                          | Startprüfung und stündliche Prüfung.                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/hourly-scan-YYYYMMDD-HHMMSS.log     | hourly-scan.sh                      | Wenn eine der vier stündlichen Kontrollen mit einem Status ungleich null endet.                                                        |
| /opt/high-fortress-user/cron/alerts/<tool>-YYYYMMDD-HHMMSS.txt                 | hf_log_alert                           | Im selben Moment wie das Sicherheitsjournal, nur wenn ein Alarm entsteht.                                                       |
| /var/log/clamav/clamonacc.log                                                  | clamonacc                           | Während der Zugriffsdienst läuft.                                                                                               |
| /var/log/lynis.log                                                             | lynis                               | Während `hf lynis` oder `verify/workstation.sh`. Modus 640.                                                                     |
| /var/log/lynis-report.dat                                                      | lynis                               | Derselbe Lauf. Modus 640.                                                                                                       |
| <source>/logs/lynis-<stamp>/                                                   | core/lynis.sh                       | Wenn Sie `sudo ./hf lynis` starten.                                                                                             |
| <source>/logs/verify-report-WORKSTATION-YYYYMMDD-HHMMSS.md                     | verify/workstation.sh               | Während der Arbeitsplatzprüfung, unter HF_LOG_DIR wenn diese Variable gesetzt ist.                                              |
| systemd journal, unit hfu-boot-chain.service                                   | systemd                             | Jede Startkette.                                                                                                                |
| systemd journal, unit hfu-boot-scan.service                                    | systemd                             | Jede Startprüfung.                                                                                                              |
| systemd journal, unit hfu-hourly-scan.service                                  | systemd                             | Jede stündliche Prüfung.                                                                                                        |
| systemd journal, unit hfu-idle-scan.service                                    | systemd                             | Jede verzögerte Prüfung.                                                                                                        |
| systemd journal, unit hfu-reboot-notice.service                                  | systemd                             | Jeder Neustart-Hinweis.                                                                                              |
