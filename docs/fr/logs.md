# Journaux

`<source>` est `/opt/high-fortress-user/src` après l'installeur curl, ou le répertoire du clone. `YYYYMMDD-HHMMSS` est l'horodatage `date +%Y%m%d-%H%M%S`.

| Chemin                                                                         | Qui écrit                           | Quand                                                                                                                                  |
| ------------------------------------------------------------------------------ | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/install.log                         | scripts/run.sh via hf_init_install_log | Pendant l'installation.                                                                                                                |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/errors.log                          | hf_log_error()                      | Lorsqu'une étape échoue.                                                                                                               |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/meta.txt                            | hf_init_install_log                    | Lorsque le répertoire de journal est créé.                                                                                             |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/steps/INDEX.tsv                     | hf_set_step_visible                             | À chaque étape d'installation.                                                                                                         |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/aide-init.log                       | service/aide/init-db.sh             | Lorsque la base est construite la première fois. Chemin de repli si HF_LOG_DIR est vide : `/var/log/high-fortress-user/aide-init.log`. |
| /opt/high-fortress-user/cron/security_logs/aide-YYYYMMDD-HHMMSS.log            | aide.sh                             | Passe de démarrage et passe horaire, lorsque AIDE tourne.                                                                              |
| /opt/high-fortress-user/cron/security_logs/rkhunter-YYYYMMDD-HHMMSS.log        | rkhunter.sh                         | Passe de démarrage et passe horaire.                                                                                                   |
| /opt/high-fortress-user/cron/security_logs/chkrootkit-YYYYMMDD-HHMMSS.log      | chkrootkit.sh                       | Passe de démarrage et passe horaire.                                                                                                   |
| /opt/high-fortress-user/cron/security_logs/clamav-YYYYMMDD-HHMMSS.log          | clamav.sh                           | Passe de démarrage et passe toutes les 2 heures.                                                                                        |
| /opt/high-fortress-user/cron/security_logs/apparmor-detect.log                 | detect-and-apply.sh                 | Chaque décision de profil AppArmor.                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/integrity-YYYYMMDD-HHMMSS.log       | integrity.sh                        | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/integrity.sha256                                  | integrity.sh                        | Passe de démarrage. La première passe l'écrit et n'envoie pas de courrier.                                                            |
| /opt/high-fortress-user/cron/security_logs/behavior-YYYYMMDD-HHMMSS.log        | behavior.sh                         | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/behavior.stamp                                    | behavior.sh                         | Passe de démarrage. La première passe l'écrit et n'envoie pas de courrier. Les passes suivantes lisent les événements d'audit depuis ce cachet. |
| /opt/high-fortress-user/cron/security_logs/egress-YYYYMMDD-HHMMSS.log          | egress-watch.sh                     | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/egress.stamp                                      | egress-watch.sh                     | Passe de démarrage. La première passe l'écrit et n'envoie pas de courrier. Les passes suivantes lisent les lignes noyau depuis ce cachet. |
| /opt/high-fortress-user/cron/quarantine.registry                           | le déplacement en quarantaine       | Lorsqu'un fichier est enregistré. Mode 600.                                                                              |
| /opt/high-fortress-user/cron/security_logs/idle-scan-YYYYMMDD-HHMMSS.log       | idle-scan.sh                        | Passe différée. Une passe propre et une passe sautée parce qu'un jeu tourne écrivent ce fichier.                               |
| /opt/high-fortress-user/cron/security_logs/reboot-notice-YYYYMMDD-HHMMSS.log | reboot-notice.sh                    | Avis de redémarrage. Une passe propre et une passe sautée parce qu'un jeu tourne écrivent ce fichier.              |
| /opt/high-fortress-user/cron/security_logs/scan-skip.log                       | apply-scan-skip.sh                  | Lorsqu'une ligne de `scan-skip.paths` est refusée.                                                                                      |
| /opt/high-fortress-user/cron/security_logs/clamav-onaccess-YYYYMMDD-HHMMSS.log | clamav-event.sh                     | Lorsqu'une analyse à l'accès trouve un vrai fichier. Un nom de verrou sort avant l'écriture de ce fichier.                                            |
| /opt/high-fortress-user/cron/security_logs/debsums-YYYYMMDD-HHMMSS.log         | debsums.sh                          | Passe de démarrage et passe horaire.                                                                                                   |
| /opt/high-fortress-user/cron/security_logs/hourly-scan-YYYYMMDD-HHMMSS.log     | hourly-scan.sh                      | Lorsqu'un des quatre contrôles horaires sort avec un code non nul.                                                                    |
| /opt/high-fortress-user/cron/alerts/<tool>-YYYYMMDD-HHMMSS.txt                 | hf_log_alert                           | Au même moment que le journal de sécurité, seulement lorsqu'une alerte est levée.                                                      |
| /var/log/clamav/clamonacc.log                                                  | clamonacc                           | Pendant que le service à l'accès tourne.                                                                                               |
| /var/log/lynis.log                                                             | lynis                               | Pendant `hf lynis` ou `verify/workstation.sh`. Mode 640.                                                                               |
| /var/log/lynis-report.dat                                                      | lynis                               | Même passage. Mode 640.                                                                                                                |
| <source>/logs/lynis-<stamp>/                                                   | core/lynis.sh                       | Lorsque vous lancez `sudo ./hf lynis`.                                                                                                 |
| <source>/logs/verify-report-WORKSTATION-YYYYMMDD-HHMMSS.md                     | verify/workstation.sh               | Pendant la vérification du poste, sous HF_LOG_DIR lorsque cette variable est posée.                                                    |
| systemd journal, unit hfu-boot-chain.service                                   | systemd                             | Chaque chaîne de démarrage.                                                                                                        |
| systemd journal, unit hfu-boot-scan.service                                    | systemd                             | Chaque passe de démarrage.                                                                                                             |
| systemd journal, unit hfu-hourly-scan.service                                  | systemd                             | Chaque passe horaire.                                                                                                                  |
| systemd journal, unit hfu-idle-scan.service                                    | systemd                             | Chaque passe différée.                                                                                                                  |
| systemd journal, unit hfu-reboot-notice.service                                  | systemd                             | Chaque avis de redémarrage.                                                                                          |
