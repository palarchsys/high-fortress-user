# Journaux

`<source>` est `/opt/high-fortress-user/src` après l'installeur curl, ou le répertoire du clone. `YYYYMMDD-HHMMSS` est l'horodatage `date +%Y%m%d-%H%M%S`.

| Chemin                                                                         | Qui écrit                           | Quand                                                                                                                                  |
| ------------------------------------------------------------------------------ | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/install.log                         | scripts/run.sh via init_install_log | Pendant l'installation.                                                                                                                |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/errors.log                          | error()                             | Lorsqu'une étape échoue.                                                                                                               |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/meta.txt                            | init_install_log                    | Lorsque le répertoire de journal est créé.                                                                                             |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/steps/INDEX.tsv                     | step_on                             | À chaque étape d'installation.                                                                                                         |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/aide-init.log                       | service/aide/init-db.sh             | Lorsque la base est construite la première fois. Chemin de repli si HF_LOG_DIR est vide : `/var/log/high-fortress-user/aide-init.log`. |
| /opt/high-fortress-user/cron/security_logs/aide-YYYYMMDD-HHMMSS.log            | aide.sh                             | Passe de démarrage, lorsque AIDE tourne.                                                                                               |
| /opt/high-fortress-user/cron/security_logs/rkhunter-YYYYMMDD-HHMMSS.log        | rkhunter.sh                         | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/chkrootkit-YYYYMMDD-HHMMSS.log      | chkrootkit.sh                       | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/clamav-YYYYMMDD-HHMMSS.log          | clamav.sh                           | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/security_logs/clamav-onaccess-YYYYMMDD-HHMMSS.log | clamav-event.sh                     | Lorsqu'une analyse à l'accès trouve un vrai fichier. Un nom de verrou sort avant l'écriture de ce fichier.                                            |
| /opt/high-fortress-user/cron/security_logs/debsums-YYYYMMDD-HHMMSS.log         | debsums.sh                          | Passe de démarrage.                                                                                                                    |
| /opt/high-fortress-user/cron/alerts/<tool>-YYYYMMDD-HHMMSS.txt                 | log_alert                           | Au même moment que le journal de sécurité, seulement lorsqu'une alerte est levée.                                                      |
| /var/log/clamav/clamonacc.log                                                  | clamonacc                           | Pendant que le service à l'accès tourne.                                                                                               |
| /var/log/lynis.log                                                             | lynis                               | Pendant `hf lynis` ou `verify/workstation.sh`. Mode 640.                                                                               |
| /var/log/lynis-report.dat                                                      | lynis                               | Même passage. Mode 640.                                                                                                                |
| <source>/logs/lynis-<stamp>/                                                   | core/lynis.sh                       | Lorsque vous lancez `sudo ./hf lynis`.                                                                                                 |
| <source>/logs/verify-report-WORKSTATION-YYYYMMDD-HHMMSS.md                     | verify/workstation.sh               | Pendant la vérification du poste, sous HF_LOG_DIR lorsque cette variable est posée.                                                    |
| systemd journal, unit hfu-boot-scan.service                                    | systemd                             | Chaque passe de démarrage.                                                                                                             |
