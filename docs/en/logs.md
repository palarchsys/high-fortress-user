# Logs

`<source>` is `/opt/high-fortress-user/src` after the curl installer, or the clone directory. `YYYYMMDD-HHMMSS` is the stamp `date +%Y%m%d-%H%M%S`.

| Path                                                                           | Who writes                          | When                                                                                                                 |
| ------------------------------------------------------------------------------ | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/install.log                         | scripts/run.sh via hf_init_install_log | During installation.                                                                                                 |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/errors.log                          | hf_log_error()                      | When a step fails.                                                                                                   |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/meta.txt                            | hf_init_install_log                    | When the log directory is created.                                                                                   |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/steps/INDEX.tsv                     | hf_set_step_visible                             | At each install step.                                                                                                |
| <source>/logs/install-YYYYMMDD-HHMMSS-user/aide-init.log                       | service/aide/init-db.sh             | When the baseline is first built. Fallback path if HF_LOG_DIR is unset: `/var/log/high-fortress-user/aide-init.log`. |
| /opt/high-fortress-user/cron/security_logs/aide-YYYYMMDD-HHMMSS.log            | aide.sh                             | Boot scan, when AIDE runs.                                                                                           |
| /opt/high-fortress-user/cron/security_logs/rkhunter-YYYYMMDD-HHMMSS.log        | rkhunter.sh                         | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/security_logs/chkrootkit-YYYYMMDD-HHMMSS.log      | chkrootkit.sh                       | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/security_logs/clamav-YYYYMMDD-HHMMSS.log          | clamav.sh                           | Boot scan and the 2-hour pass.                                                                                       |
| /opt/high-fortress-user/cron/security_logs/apparmor-detect.log                 | detect-and-apply.sh                 | Each AppArmor profile decision.                                                                                      |
| /opt/high-fortress-user/cron/security_logs/integrity-YYYYMMDD-HHMMSS.log       | integrity.sh                        | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/integrity.sha256                                  | integrity.sh                        | Boot scan. The first pass writes it and does not send mail.                                                         |
| /opt/high-fortress-user/cron/security_logs/behavior-YYYYMMDD-HHMMSS.log        | behavior.sh                         | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/behavior.stamp                                    | behavior.sh                         | Boot scan. The first pass writes it and does not send mail. Later passes read audit events since this stamp.       |
| /opt/high-fortress-user/cron/security_logs/egress-YYYYMMDD-HHMMSS.log          | egress-watch.sh                     | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/egress.stamp                                      | egress-watch.sh                     | Boot scan. The first pass writes it and does not send mail. Later passes read kernel lines since this stamp.       |
| /opt/high-fortress-user/cron/security_logs/idle-scan-YYYYMMDD-HHMMSS.log       | idle-scan.sh                        | Idle scan. A clean pass and a pass skipped because a game is running both write this file.                         |
| /opt/high-fortress-user/cron/security_logs/reboot-notice-YYYYMMDD-HHMMSS.log | reboot-notice.sh                    | Reboot notice. A clean pass and a pass skipped because a game is running both write this file.                     |
| /opt/high-fortress-user/cron/security_logs/scan-skip.log                       | apply-scan-skip.sh                  | When a line of `scan-skip.paths` is refused.                                                                         |
| /opt/high-fortress-user/cron/security_logs/clamav-onaccess-YYYYMMDD-HHMMSS.log | clamav-event.sh                     | When on-access finds a real file. A lock name exits before this file is written.                                                |
| /opt/high-fortress-user/cron/security_logs/debsums-YYYYMMDD-HHMMSS.log         | debsums.sh                          | Boot scan.                                                                                                           |
| /opt/high-fortress-user/cron/alerts/<tool>-YYYYMMDD-HHMMSS.txt                 | hf_log_alert                           | Same moment as the security journal, only when an alert is raised.                                                   |
| /var/log/clamav/clamonacc.log                                                  | clamonacc                           | While the on-access service runs.                                                                                    |
| /var/log/lynis.log                                                             | lynis                               | During `hf lynis` or `verify/workstation.sh`. Mode 640.                                                              |
| /var/log/lynis-report.dat                                                      | lynis                               | Same run. Mode 640.                                                                                                  |
| <source>/logs/lynis-<stamp>/                                                   | core/lynis.sh                       | When you run `sudo ./hf lynis`.                                                                                      |
| <source>/logs/verify-report-WORKSTATION-YYYYMMDD-HHMMSS.md                     | verify/workstation.sh               | During workstation verification, under HF_LOG_DIR when that variable is set.                                         |
| systemd journal, unit hfu-boot-chain.service                                   | systemd                             | Each boot chain.                                                                                                     |
| systemd journal, unit hfu-boot-scan.service                                    | systemd                             | Each boot scan.                                                                                                      |
| systemd journal, unit hfu-idle-scan.service                                    | systemd                             | Each idle scan.                                                                                                      |
| systemd journal, unit hfu-reboot-notice.service                                  | systemd                             | Each reboot notice.                                                                                                  |
